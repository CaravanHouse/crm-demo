# Savdo CRM — демо CRM-системы

Демо от [CaravanHouse](https://caravanhouse.uz): CRM для вымышленной мебельной компании «Dekor Mebel».
Живая версия: https://crm.caravanhouse.uz

Что показывает демо:
- **Дашборд**: выручка, сделки в работе, конверсия, средний чек; график выручки по месяцам, источники клиентов, воронка, задачи на сегодня, лента событий. Цифры пересчитываются, когда двигаете сделки.
- **Сделки (канбан)**: перетаскивание карточек между этапами, суммы по колонкам. На телефоне колонки листаются, этап меняется в карточке.
- **Карточка сделки**: этапы, «успешно / отказ», клиент, менеджер, история с заметками.
- **Клиенты**: поиск по имени и телефону, фильтр по источнику, сумма сделок.
- **Задачи**: просрочено / сегодня / завтра / позже, отметка выполнения, быстрое добавление.
- **Заявки в реальном времени**: каждые ~35 секунд «прилетает» новая заявка из Telegram-бота — с уведомлением и подсветкой в воронке.
- Глобальный поиск, создание сделки, русский и узбекский (`/ru`, `/uz`).

Это демо: компания, клиенты и цифры вымышленные. Данные хранятся в `localStorage` браузера, кнопка «Сбросить демо» возвращает исходное состояние. В настоящем проекте здесь сервер, база данных, вход сотрудников и интеграции (Telegram-бот, сайт, телефония).

Стек: Next.js 16, React 19, TypeScript, Tailwind CSS 4. Хостинг — Vercel.

```bash
npm install
npm run dev   # http://localhost:3000
```

Хотите CRM под свой бизнес — [напишите нам в Telegram](https://t.me/CaravanHousebot?start=demo_crm).
